# 프리미엄 결제 - 공고 선택 후 결제창 열기 (구현 예정)

## 개요
현재는 PG 테스트를 위해 공고 선택 없이 바로 결제창으로 이동합니다.
추후 아래 로직을 복원하여 **공고 선택 → 결제** 플로우를 적용해야 합니다.

## 복원 위치
`src/app/premium/page.tsx` — `handleSelectJob` 함수

## 복원할 플로우
1. 유료 티어 클릭 → 공고 선택 모달 열림
2. 내 공고 목록 + 결제 내역 동시 조회
3. 공고 선택 (업그레이드 가능 여부 체크)
4. 결제하기 클릭 → 체크아웃 페이지로 이동 (jobId 포함)

## 복원할 코드 (handleSelectJob)

```tsx
// 공고 선택 모달 열기 (유료 티어만)
const handleSelectJob = async (tier: string) => {
  if (tier === 'normal') {
    // 무료 공고는 바로 작성 페이지로
    window.location.href = selectedCategory === 'agent' ? '/agent/jobs/new' : '/sales/jobs/new';
    return;
  }

  if (!user) {
    alert('결제를 진행하려면 로그인이 필요합니다.');
    window.location.href = '/agent/auth/login';
    return;
  }

  setSelectedTier(tier);
  setSelectedJobId(null);
  setJobsLoading(true);
  setShowJobModal(true);

  try {
    // 내 공고 목록 + 결제 내역 동시 조회
    const [jobs, paymentsRes] = await Promise.all([
      fetchMyJobs(user.id),
      session?.access_token
        ? fetch('/api/payments/my', {
            headers: { Authorization: `Bearer ${session.access_token}` },
          }).then(r => r.json())
        : Promise.resolve({}),
    ]);

    // 현재 카테고리의 공고만 필터
    const filteredJobs = (jobs as MyJob[]).filter(
      (j) => j.category === selectedCategory
    );
    setMyJobs(filteredJobs);
    setJobPayments(paymentsRes || {});
  } catch (err) {
    console.error('공고 목록 조회 실패:', err);
    setMyJobs([]);
  } finally {
    setJobsLoading(false);
  }
};
```

## 복원할 모달 UI (공고 선택 모달)

프리미엄 페이지 하단에 이미 공고 선택 모달 JSX가 존재합니다 (`{showJobModal && selectedTier && (...)}`).
`handleSelectJob`을 복원하면 모달이 자동으로 다시 작동합니다.

## 모달 내 결제 버튼
공고 선택 후 "프리미엄 결제하기" 버튼 클릭 시:
```tsx
onClick={() => {
  if (selectedJobId) {
    handlePayment(selectedTier!, selectedJobId);
  }
}}
```

## 복원 방법
1. `handleSelectJob` 함수를 위 코드로 교체
2. 프리미엄 페이지의 CTA 버튼 onClick을 `handleSelectJob(plan.tier)`로 되돌리기
   (현재: `handlePayment(plan.tier)` → 복원: `handleSelectJob(plan.tier)`)
