## 1. 목표

분양상담사 광고 상품을 **4등급 × 기간선택(10/20/30일)** 구조로 개편한다.
한 등급 안에서 기간을 고르면 가격이 비례해 바뀌고, "20일 구매 시 +10일 무료" 보너스로
체감 가치를 높인다. 현재의 "특별가(90% 할인)"는 걷어내고 정가를 실가격으로 승격한다.

## 3. 가격 정책 (확정)

브랜드 톤 유지 + 신규 150,000원 등급 "다이아" 추가. (공인중개사도 동일 구조로 가되 UI 연결은 다음 작업)

| 가격(공급가, 10일 기준) | 분양상담사 | tier id | 기간 구조 |
|---|---|---|---|
| 49,000 | 프리미엄 | `premium` | **7일 + 7일 무료 = 14일 (단일·고정)** |
| 99,000 | 슈페리어 | `superior` | 10 / 20(+10) / 30일 |
| 150,000 | 다이아 ⭐신규 | `dia` | 10 / 20(+10) / 30일 |
| 249,000 | 유니크 | `unique` | 10 / 20(+10) / 30일 · **지역 독점·보너스 없음** |
| 0 | 일반(무료) | `normal` | 상시/24시간 (기존 유지) |

### 기간별 가격 매트릭스 (공급가, VAT 10% 별도)

> 보너스: **"20일 구매 시 +10일 무료"** (입문은 "7일+7일", 유니크는 보너스 없음). 노출일 = 구매일 + 보너스일.

| 등급 | 10일 | 20일 (+10 → 30일 노출) | 30일 |
|---|---|---|---|
| 프리미엄(입문) | — | — | 49,000 / 7+7=14일 단일 |
| 슈페리어 | 99,000 | **198,000 (30일 노출)** | 297,000 |
| 다이아 | 150,000 | **300,000 (30일 노출)** | 450,000 |
| 유니크 | 249,000 | 498,000 (20일) | 747,000 |

20일 옵션(+10일)이 주력 SKU, 30일은 비교 미끼(decoy).

### 할인 연출 (우리 할인율)

- 최종가는 위 확정값. `listPrice`(정가 취소선)는 **오픈 특별가 ~30% 연출용 앵커**.
- 규칙: `listPrice = round(price / 0.7, 10000)` (≈30%↓). 마케팅 조정 가능.
  - 예: 프리미엄 49,000 → 70,000 / 슈페리어 10일 99,000 → 140,000 / 다이아 10일 150,000 → 210,000 / 유니크 10일 249,000 → 360,000
- 헤더 카피 **"오픈 기념 90% 할인" → "오픈 기념 특별가"** 로 변경 (90%는 더 이상 성립 안 함).

## 4. 데이터 구조 (`src/lib/toss.ts`) — 단일 출처

toss.ts를 **유일한 가격 출처**로 만든다. `AD_PRODUCTS`와 `PRICING_DATA`는 가격을 제거하고
toss.ts에서 읽는다(표현 정보 features·색상·아이콘·tagline·preview 매핑만 로컬 유지).

```ts
export interface DurationOption {
  days: number;        // 7, 10, 20, 30
  bonusDays: number;   // 0 | 7 | 10
  price: number;       // 공급가액 (VAT 별도)
  listPrice?: number;  // 정가 취소선 (없으면 미표시)
}
export interface PricingTier {
  id: string;          // 'premium' | 'superior' | 'dia' | 'unique' (+ agent용도 정의)
  name: string;
  category: 'agent' | 'sales';
  exclusive: boolean;  // 유니크/VIP 지역독점
  options: DurationOption[];  // 입문 길이 1, 나머지 3
}
export function getExposureDays(o: DurationOption): number { return o.days + o.bonusDays; }
export function getDiscountRate(o: DurationOption): number | null { /* listPrice 기준 % */ }
export function findOption(category, id, days): DurationOption | undefined;
// 기존 getVat()/getTotalPrice()/generateOrderId() 재사용
```

- 키: `Record<string, PricingTier>`, key = `{category}-{id}` (예: `sales-dia`)
- **agent 4등급 데이터도 toss.ts에 함께 정의**해 둠 (다음 리모델 때 UI만 연결). 단 이번엔 agent UI 미수정.
