## 카카오맵 '1앱-1서비스' 정책 (2024~)

> **계정 내 첫 번째 앱에는 카카오맵 API 호출 권한이 자동 부여**
> 두 번째 이후 앱은 별도 심사 필요. 심사 시 기존 앱 정보까지 모두 양식 작성.

**Why**: 무료 쿼터 어뷰징 방지가 목적. 같은 회사가 여러 서비스 운영하는 정상 케이스는 한 앱에 여러 도메인 등록으로 우회 가능.

**How to apply**:
- 신규 카카오맵 통합 시 무조건 첫 번째 앱(99928cf1) 키 사용
- onsia-job 앱은 카카오맵 외 다른 용도(예: 카카오 로그인)로 분리 가능
- 같은 도메인을 두 앱에 등록 금지
