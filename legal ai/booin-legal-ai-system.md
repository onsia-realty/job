# BOOIN 부동산 법률 AI 검색 시스템 기획서

> **프로젝트명:** 부인(BOOIN) 부동산 법률 AI 검색 시스템  
> **적용 사이트:** https://www.booin.co.kr  
> **작성일:** 2026-03-08  
> **작성:** 온시아 주식회사

---

## 1. 프로젝트 개요

### 1.1 현재 상태
- booin.co.kr에 "AI 비서" 기능이 존재하나, Gemini API 단순 연동 수준
- 판례, 조문, 행정해석 등 법률 데이터 기반 검색 기능 없음
- 부동산 실무자(분양상담사, 공인중개사)가 필요로 하는 법률 정보 제공 불가

### 1.2 목표
**공공데이터 API를 활용하여 부동산·세금·분쟁 관련 판례, 법령 조문, 행정해석을 AI가 검색·분석하여 답변하는 시스템 구축**

### 1.3 벤치마크
- LBOX(엘박스) — 법률 전문 AI 검색 플랫폼 (전체 법률 범용)
- BOOIN은 **부동산·세금 특화**로 차별화

### 1.4 핵심 차별점
| 항목 | LBOX | BOOIN 법률 AI |
|------|------|---------------|
| 범위 | 전체 법률 210만건 | 부동산·세금 특화 |
| 비용 | 유료 구독 (월 수만원~) | 기본 무료, 심층분석 유료 |
| 타깃 | 변호사, 법무 | 분양상담사, 중개사, 일반인 |
| 데이터 | 자체 수집 + 독점 콘텐츠 | 공공데이터 API 기반 |
| 부가가치 | 변호사 매칭 | 분양·중개 플랫폼 연계 |

## 2. 공공데이터 API 소스 목록

### 2.1 판례 검색 (핵심)

#### A. 국가법령정보센터 — 판례 목록 조회 API
- **제공기관:** 법제처
- **신청 사이트:** https://open.law.go.kr
- **요청 URL:** `http://www.law.go.kr/DRF/lawSearch.do?target=prec`
- **인증:** OC (사용자 이메일 ID)
- **출력 형식:** XML, JSON, HTML
- **주요 요청 변수:**

| 변수 | 값 | 설명 |
|------|-----|------|
| `OC` | string (필수) | 사용자 이메일 ID |
| `target` | `prec` (필수) | 판례 검색 |
| `type` | `XML` / `JSON` / `HTML` | 출력 형태 |
| `search` | 1 또는 2 | 1: 판례명, 2: 본문검색 |
| `query` | string | 검색 키워드 |
| `display` | int (기본20, 최대100) | 결과 개수 |
| `page` | int | 페이지 번호 |
| `org` | string | 법원종류 (대법원: 400201, 하위법원: 400202) |
| `curt` | string | 법원명 |
| `JO` | string | 참조법령명 (민법, 부동산실거래법 등) |
| `sort` | string | 정렬 (ddes: 선고일 내림차순 등) |
| `prncYd` | string | 선고일자 범위 (20090101~20090130) |

- **출력 필드:** 판례일련번호, 사건명, 사건번호, 선고일자, 법원명, 사건종류명, 판결유형, 판례상세링크
- **샘플 요청:**
```
# 부동산 관련 판례 검색
http://www.law.go.kr/DRF/lawSearch.do?OC=onsia&target=prec&type=JSON&query=부동산&search=2

# 임대차 관련 대법원 판례
http://www.law.go.kr/DRF/lawSearch.do?OC=onsia&target=prec&type=JSON&query=임대차&curt=대법원
```

#### B. 국가법령정보센터 — 판례 본문 조회 API
- **요청 URL:** `http://www.law.go.kr/DRF/lawService.do?target=prec`
- **용도:** 판례 목록에서 얻은 판례일련번호로 판결문 전문(본문) 조회
- **주요 요청 변수:**

| 변수 | 값 | 설명 |
|------|-----|------|
| `OC` | string (필수) | 사용자 이메일 ID |
| `target` | `prec` (필수) | 판례 본문 |
| `type` | `XML` / `JSON` / `HTML` | 출력 형태 |
| `ID` | int (필수) | 판례일련번호 |

- **출력 필드:** 판례정보일련번호, 사건명, 사건번호, 선고일자, 선고, 법원명, 법원종류코드, 사건종류명, 판시사항, 판결요지, 참조조문, 참조판례, 판례내용(전문)

#### C. 공공데이터포털 — 판례 목록/본문 조회
- **신청 사이트:** https://www.data.go.kr
- **판례 목록:** https://www.data.go.kr/data/15059269/openapi.do
- **판례 본문:** https://www.data.go.kr/data/15057123/openapi.do
- **인증:** 공공데이터포털 서비스키 (API Key)
- **참고:** 법제처 API와 데이터 동일, 인증 방식만 다름

### 2.2 법령 조문 검색

#### A. 국가법령정보 공유서비스 — 법령 검색 API
- **신청:** https://open.law.go.kr 또는 https://www.data.go.kr/data/15000115/openapi.do
- **요청 URL:** `http://www.law.go.kr/DRF/lawSearch.do?target=law`
- **주요 요청 변수:**

| 변수 | 값 | 설명 |
|------|-----|------|
| `OC` | string (필수) | 사용자 이메일 ID |
| `target` | `law` (필수) | 법령 검색 |
| `type` | `XML` / `JSON` / `HTML` | 출력 형태 |
| `query` | string | 검색 키워드 |
| `display` | int | 결과 개수 |
| `page` | int | 페이지 번호 |
| `org` | int | 소관부처 코드 |
| `MST` | int | 법령 ID (특정 법령 직접 조회) |

- **부동산 관련 주요 법령 키워드:**
  - 공인중개사법
  - 부동산 거래신고 등에 관한 법률
  - 주택법
  - 주택임대차보호법
  - 상가건물 임대차보호법
  - 부동산등기법
  - 건축법
  - 도시 및 주거환경정비법 (재개발·재건축)
  - 도시개발법
  - 택지개발촉진법
  - 공익사업을 위한 토지 등의 취득 및 보상에 관한 법률
  - 민법 (물권편, 채권편)

#### B. 법령 본문 조문 조회 API
- **요청 URL:** `http://www.law.go.kr/DRF/lawService.do?target=law`
- **용도:** 특정 법령의 전체 조문 또는 특정 조항 조회
- **출력:** 법령명, 조문번호, 조문내용, 시행일자, 개정이력 등

### 2.3 행정해석·법령해석례

#### A. 국가법령정보센터 — 법령해석례 API
- **요청 URL:** `http://www.law.go.kr/DRF/lawSearch.do?target=expc`
- **주요 요청 변수:**

| 변수 | 값 | 설명 |
|------|-----|------|
| `OC` | string (필수) | 사용자 이메일 ID |
| `target` | `expc` (필수) | 법령해석례 |
| `type` | `XML` / `JSON` | 출력 형태 |
| `query` | string | 검색 키워드 |
| `display` | int | 결과 개수 |
| `page` | int | 페이지 번호 |

- **용도:** 법제처가 각 부처 요청으로 회신한 법령 해석 사례 (행안부 공문 포함)
- **부동산 관련 활용:** 주택법·공인중개사법·임대차보호법 관련 질의회신 검색 가능

#### B. 행정안전부 법령해석 API (공공데이터포털)
- **목록 조회:** https://www.data.go.kr/data/15140311/openapi.do
- **본문 조회:** https://www.data.go.kr/data/15140312/openapi.do
- **제공 내용:** 행안부 관할 사무(지방자치, 주민등록 등)에 대한 법령 해석 회신
- **포함 정보:** 해석 일련번호, 안건명, 질의기관, 해석일자, 질의 배경, 관련 법령 조항, 법리적 해석, 판단 근거

### 2.4 세금 관련 데이터

#### A. 국세법령정보시스템 (taxlaw.nts.go.kr)
- **직접 API:** 별도 Open API 미제공 (웹 크롤링 또는 법제처 API 활용)
- **제공 내용:**
  - 세법령 (소득세법, 법인세법, 부가가치세법, 종합부동산세법, 지방세법 등)
  - 세법 해석례 (질의회신, 예규)
  - 심사·심판청구 결정문
  - 법원 세금 관련 판례
  - 기본통칙, 고시, 훈령
- **대안 접근:** 법제처 판례 API에서 `query=양도소득세`, `query=취득세`, `query=종합부동산세` 등으로 검색

#### B. 조세심판원 행정심판 재결례 API
- **신청:** https://www.data.go.kr/data/15140320/openapi.do
- **제공기관:** 법제처 (국가법령정보센터 경유)
- **제공 내용:** 조세심판원이 결정한 행정심판 재결례 목록 및 본문
- **부동산 관련 활용:** 양도세·취득세·종부세 불복 심판 결정례 검색

#### C. 법제처 API 세금 키워드 활용
```
# 양도소득세 관련 판례
http://www.law.go.kr/DRF/lawSearch.do?OC=onsia&target=prec&type=JSON&query=양도소득세&search=2

# 취득세 관련 판례
http://www.law.go.kr/DRF/lawSearch.do?OC=onsia&target=prec&type=JSON&query=취득세&search=2

# 종합부동산세 법령해석례
http://www.law.go.kr/DRF/lawSearch.do?OC=onsia&target=expc&type=JSON&query=종합부동산세
```

### 2.5 부동산 분쟁 관련 추가 데이터

#### A. 중앙토지수용위원회 재결례

- **데이터:** 토지보상 관련 재결 사례

- **데이터:** 임대차 분쟁 조정 사례
- **접근:** 현재 체계적 API 미제공 → 법제처 판례 API에서 "임대차분쟁" 키워드 활용

- **사이트:** https://openapi.scourt.go.kr
- **제공:** 법원 공공데이터 API 서비스
- **활용:** 판결문 추가 데이터 보완

### 5.1 검색 플로우

```
사용자 질문 입력
    │
    ▼
[1] 질문 분석 (Claude API)
    - 카테고리 분류 (거래/임대차/세금/등기/재개발/건축/토지)
    - 핵심 키워드 추출
    - 관련 법령명 추정
    │
    ▼
[2] 하이브리드 검색 (병렬 실행)
    ├── (A) 벡터 유사도 검색 (Supabase pgvector)
    │       → 사전 수집된 판례·조문·해석례 중 유사한 것
    │
    ├── (B) 실시간 API 호출 (법제처)
    │       → 최신 판례·법령 실시간 조회
    │
    └── (C) 키워드 기반 DB 검색
            → 카테고리별 태깅된 데이터 필터링
    │
    ▼
[3] 결과 병합 및 랭킹
    - 유사도 점수 + 최신도 + 관련성 종합 스코어링
    - 상위 5~10건 선별
    │
    ▼
[4] 답변 생성 (Claude API)
    - 선별된 판례/조문/해석례를 컨텍스트로 전달
    - 출처(사건번호, 법령 조항, 해석례 번호) 반드시 포함
    - 실무 적용 포인트 요약
    │
    ▼
[5] 응답 반환
    - 답변 텍스트
    - 출처 목록 (링크 포함)
    - 관련 판례 카드 (사건명, 선고일, 요지)
    - "더 자세히 보기" → 원문 링크
```

- 법령 조문: **공공저작물** → 자유 이용 가능
- 법령해석례: **공공저작물** → 자유 이용 가능
- 공공데이터포털 API: **「공공데이터의 제공 및 이용 활성화에 관한 법률」** 에 따라 상업적 이용 가능

### 10.2 면책 고지 (필수)
```
본 서비스는 공공데이터를 기반으로 한 AI 참고 정보 제공 서비스이며,
법률 자문이 아닙니다. 구체적 법률 문제에 대해서는 반드시 전문
변호사의 상담을 받으시기 바랍니다.

제공되는 판례 및 법령 정보는 검색 시점의 데이터를 기반으로 하며,
최신 개정 사항이 즉시 반영되지 않을 수 있습니다.
```

### 10.3 주의사항
- AI 답변에 "법률 자문"이라는 표현 사용 금지 → "법률 정보 검색 서비스"로 명시
- 변호사법 위반 소지 차단 (비변호사의 법률사무 취급 금지)
- 답변 말미에 항상 면책 고지 포함
